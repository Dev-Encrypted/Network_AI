# NETWORK AI v0.2.0: private inference application

This release connects the PT-BR interface, NestJS/Fastify control service, PostgreSQL, and Rust gateway/node. A request passes through quoting, a balance hold, physical-domain admission, real local inference and signed receipt settlement.

## Included

- Streaming chat, immutable model candidates, sessions, LAB_TU balances, personal API keys, and user/node administration.
- Ed25519 identity, one-time invitations, replay controls, node epochs, request-bound capabilities, cancellation and receipt outbox.
- Balanced journals, protected balance projections, idempotent charging, account isolation and verified backup restoration.
- Local initialization with private credentials, checksum-tracked migrations, and protection against replacing an existing database from another checkout.

## Validation and limits

The local campaign recorded 18 PostgreSQL integration tests, six Rust tests, 21 Python tests and four browser journeys. It also exercised real inference, cancellation, agent restart, control outage with receipt recovery, two agents in one physical domain, and isolated database restoration. CI checks source/build, database behavior and browser paths that do not require the local GPU.

Evidence is limited to one physical host and its configured local model. The project recommends models above 27B as its main focus, but this release does not implement automatic cross-node model splitting or demonstrate a distributed model above that size.

The public decentralized network, cooperative readiness economy and real payments remain unqualified. LAB_TU is a test unit, with no cash withdrawal or guarantee of future capacity. The rejected F0 economic configuration and original artifacts remain preserved.
