# v0.3.0: Private node links, availability contracts and a 32B CPU cluster

The private application can now carry the node protocol through authenticated QUIC peers, pay explicitly funded readiness windows, and adjust temporary request allowances to demand. A verified official Qwen3-32B GGUF also ran locally and across two trusted CPU worker processes, then completed and settled through the Network AI API.

## Delivered

- Rust `network-ai-link` with pinned transport identities, bounded streaming, permitted-route enforcement, connection/request limits and private operator profiles.
- PostgreSQL availability contracts with escrow, provider acceptance, observed readiness payments, fixed terms, one active contract per declared physical domain, exact refunds and audit events.
- Temporary 1/2/4 account/model admission quotas that preserve existing accepted sessions; balances and prices are unchanged by quota expansion.
- Resumable, size- and SHA-256-verified acquisition from pinned model manifests, with path/junction and non-executable-format controls.
- A supervised trusted CPU cluster adapter, protected engine API key, optional private catalog installation and managed start/stop.
- PT-BR contract controls with desktop/mobile browser validation; detailed English operator, protocol, accounting and model documentation.

## Actual larger-model result

The official Qwen3-32B Q4_K_M artifact is 19,762,149,024 bytes at revision `938a7432affaec9157f883a87164e2646ae17555`. The initial default-repacking comparison matched two of three token sequences. With CPU repacking disabled in both paths, three of three matched. Both results are preserved.

The split path placed model buffers on both CPU RPC workers. The integrated API request completed with 18 input and nine output tokens in 5,269 ms and settled successfully. These measurements use **one physical host**, a 2,048-token context, one slot and a small fixture set. They do not establish arbitrary-input numerical equivalence, a commercial service envelope or WAN performance.

## Validation and boundaries

The release adds real PostgreSQL, QUIC, artifact and browser checks to the preserved research suite. See [the implementation matrix](https://github.com/Dev-Encrypted/Network_AI/blob/main/docs/implementation/STATUS.md) and [machine-readable evidence](https://github.com/Dev-Encrypted/Network_AI/blob/main/docs/implementation/validation-v0.3.json).

This is a **private preview**. Relay/CGNAT qualification, independent participant-stage reservations and metering, adversarial verification, federated consensus, accepted cooperative economics, real payments and a funded operational pilot remain unfinished. Upstream ggml RPC is an insecure prototype and is restricted to the trusted loopback CPU experiment. Public launch gates remain closed.
