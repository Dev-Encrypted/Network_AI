# Published experiment runs

These directories preserve F0 reports, selected samples and logs from September 14, 2026, including failed attempts. The [execution record](../../docs/execution/README.md) identifies which run supports each conclusion and its limits.

The two economic `runs.jsonl.gz` archives are distributed in the complete [research release package](../../docs/publication/README.md) to keep the source checkout smaller. Their expected hashes appear in the associated `report.json` files.

Restore evidence using the documented selective restorer before full economic verification. It checks the package and extracts only the two raw archives and six historical planning ZIPs, preserving current source and documentation.

New experiments use new names and directories. Never overwrite a failed run to make it appear successful. Original fixture content, logs, machine-readable values and paths retain their original language and bytes. Their maintained English interpretation is in the execution documentation.
